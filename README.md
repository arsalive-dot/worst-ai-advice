An entry for make.fun's [Worst AI Advice: The 48-Hour Tight Line Open](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580) bounty: one line of the worst possible advice an AI could give, in 140 characters or fewer — an alarm every 20 minutes, so you never oversleep again.

`main.py` (Python 3, stdlib only) writes the line to `/output/entry.txt`, deterministically, via a temp file plus rename with mode 644.
